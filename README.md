# ✅ Lista de Tarefas

Lista de tarefas simples e leve pra organizar o que você precisa fazer. Adicione, conclua, marque as importantes e acompanhe seu progresso — tudo salvo no navegador, offline e sem cadastro.

## O que faz

- **Adicionar** tarefas num toque e concluir com o checkbox
- **Marcar como importante** (estrela) — sobe pro topo da lista
- **Editar** o texto clicando na tarefa
- **Filtros**: Todas · Pendentes · Concluídas
- **Barra de progresso** mostrando quanto você já concluiu
- **Limpar concluídas** de uma vez
- **Salva sozinho** no navegador — fecha e abre que tudo continua lá
- 100% **responsivo** e **offline**

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion · Lucide. Sem banco — tudo no `localStorage`.

## Rodar localmente

```bash
npm install
npm run dev
```

Abre em `http://localhost:3000`.
